# 🎵 Coloque Suas Músicas Aqui

## Como Usar:

1. **Coloque seus arquivos MP3 nesta pasta**
   - Exemplo: `musica1.mp3`, `musica2.mp3`, etc

2. **Edite o arquivo:** `client/src/contexts/CoupleContext.tsx`

3. **Adicione as informações das músicas:**
   ```javascript
   audioUrl: '/musicas/nome-do-arquivo.mp3'
   ```

4. **Salve e atualize o navegador**

---

## 📝 Exemplo:

Se você colocar `amor.mp3` aqui, use:
```javascript
audioUrl: '/musicas/amor.mp3'
```
