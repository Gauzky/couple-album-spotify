# 💕 Nosso Álbum - Spotify Style\n\nUm site premium e romântico de álbum de casal, inspirado no design elegante do Spotify, com player de música, galeria de fotos e contador de relacionamento.\n\n## 🎨 Características\n\n✨ **Design Premium**\n- Tema escuro cinematográfico com acentos em rosa e vermelho\n- Glassmorphism elegante em todos os componentes\n- Animações suaves e transições modernas\n- Responsivo para mobile e desktop\n\n🎵 **Player de Música**\n- Interface estilo Spotify com controles intuitivos\n- Barra de progresso animada\n- Controle de volume\n- Navegação entre músicas\n- Fundo dinâmico baseado na capa da música\n\n📸 **Galeria de Fotos**\n- Layout tipo Pinterest com cards em glassmorphism\n- Modal para visualizar fotos em tamanho grande\n- Efeitos hover elegantes\n- Suporte a legendas e datas\n\n⏱️ **Contador de Relacionamento**\n- Exibe tempo junto em dias, horas, minutos e segundos\n- Atualização em tempo real\n- Design elegante e emocional\n\n💬 **Mensagem Romântica**\n- Animação suave ao carregar\n- Personalização fácil\n- Efeito fade-in elegante\n\n✨ **Efeitos Visuais**\n- Partículas animadas no fundo\n- Brilho dinâmico nos elementos\n- Cursor personalizado\n- Loader animado\n\n## 🚀 Como Usar\n\n### Instalação\n\n```bash\ncd couple-album-spotify\npnpm install\npnpm dev\n```\n\nO site estará disponível em `http://localhost:3000`\n\n### Customização\n\n#### 1. **Adicionar/Editar Músicas**\n\nEdite o arquivo `client/src/contexts/CoupleContext.tsx` e modifique o array `songs`:\n\n```typescript\nsongs: [\n  {\n    id: '1',\n    title: 'Nome da Música',\n    artist: 'Nome do Artista',\n    duration: 218, // em segundos\n    coverUrl: 'URL_DA_CAPA', // URL da imagem da capa\n    audioUrl: 'URL_DO_AUDIO', // Opcional\n  },\n  // ... mais músicas\n]\n```\n\n#### 2. **Adicionar Fotos**\n\nAs fotos podem ser adicionadas de duas formas:\n\n**Opção A: Diretamente no código**\n\nEdite `client/src/contexts/CoupleContext.tsx`:\n\n```typescript\nphotos: [\n  {\n    id: '1',\n    url: 'URL_DA_FOTO',\n    caption: 'Legenda da foto',\n    date: '15 de Janeiro de 2023',\n  },\n  // ... mais fotos\n]\n```\n\n**Opção B: Criar página de upload (requer upgrade para web-db-user)**\n\n#### 3. **Personalizar Data de Relacionamento**\n\nEdite `client/src/contexts/CoupleContext.tsx`:\n\n```typescript\ncoupleStartDate: new Date('2023-01-15'), // Altere para sua data\n```\n\n#### 4. **Editar Mensagem Romântica**\n\nEdite `client/src/contexts/CoupleContext.tsx`:\n\n```typescript\nromanticMessage: 'Sua mensagem aqui 💕',\n```\n\n#### 5. **Personalizar Cores**\n\nEdite `client/src/index.css` e modifique as cores no `:root`:\n\n```css\n:root {\n  --primary: #ff6b9d; /* Rosa principal */\n  --accent: #ff6b9d; /* Acentos */\n  --background: #0f0f0f; /* Fundo */\n  /* ... mais cores */\n}\n```\n\n#### 6. **Editar Tipografia**\n\nAs fontes estão definidas em `client/index.html` e `client/src/index.css`:\n- **Playfair Display**: Títulos e headings\n- **Poppins**: Subtítulos e acentos\n- **Inter**: Texto do corpo\n\n## 📁 Estrutura do Projeto\n\n```\nclient/\n├── src/\n│   ├── components/\n│   │   ├── MusicPlayer.tsx       # Player de música\n│   │   ├── RelationshipCounter.tsx # Contador de tempo\n│   │   ├── PhotoGallery.tsx       # Galeria de fotos\n│   │   ├── RomanticMessage.tsx    # Mensagem romântica\n│   │   └── ParticleBackground.tsx # Partículas animadas\n│   ├── contexts/\n│   │   └── CoupleContext.tsx      # Contexto com dados do casal\n│   ├── hooks/\n│   │   └── useRelationshipTime.ts # Hook para calcular tempo\n│   ├── pages/\n│   │   └── Home.tsx               # Página principal\n│   ├── App.tsx                    # App principal\n│   └── index.css                  # Estilos globais\n└── index.html                     # HTML principal\n```\n\n## 🎵 Sobre as
